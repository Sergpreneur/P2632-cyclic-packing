# A twelve-orbit cyclic 3-(31,5,1) packing

**Author:** Nefedov Sergey  
**Affiliation:** Moscow State University, Mathematics Department  
**Manuscript:** [Preprint (PDF)](paper/main.pdf) · [LaTeX source](paper/main.tex)  
**Repository release:** v0.2.0 (16 October 2026)

## Mathematical result

We provide 12 five-element base blocks in the cyclic group Z/31Z whose 31 translations each form a cyclic 3-(31,5,1) packing. The resulting collection has **372 distinct developed five-sets and 3,720 distinct triples**, without any repeated triple. This establishes the lower bound

> **12 <= M(31,5,3) <= 13**.

The upper bound 13 follows from counting triple incidences through a fixed pair. **We have not proved that 13 orbits are impossible, and therefore have not determined the exact optimum.** The improvement is relative to the nine-orbit construction in the [TheoremDB P2632](https://theoremdb.org/statements/P2632/) research snapshot dated 25 July 2026. A complete global literature priority audit remains necessary.

## Verify the published 12-block witness

Requires Python 3, a C++17 compiler, and standard POSIX shell utilities. No special Python packages are necessary for witness verification.

```bash
python3 verify/verify_packing.py certificates/constructions/packing_12.json

g++ -O2 -std=c++17 verify/independent_checker.cpp -o /tmp/p2632-independent-checker
/tmp/p2632-independent-checker certificates/constructions/packing_12.txt

python3 lean/verification/check_model_independently.py
```

Or run the complete external checks and verify the witness digest:

```bash
bash scripts/verify_all.sh
```

The stable plaintext witness is [`certificates/constructions/packing_12.txt`](certificates/constructions/packing_12.txt). Its SHA-256 is

```text
bd23ca1859c55628896d6ff76cffe5b0db9291976fc0f7745195d44ce3d78e18
```

## Compile the Lean 4 candidate formalizations

[Lean 4](https://lean-lang.org/) is pinned to **v4.35.0** by `lean/lean-toolchain`. The project uses the bundled `Std` library and has no Mathlib dependency.

```bash
cd lean
lake build
lake env lean P2632.lean
lake env lean ResourceCertificate.lean
```

`P2632.exists_twelve_orbit_packing` uses direct translation/triple enumeration and `native_decide`, which relies on Lean's native compiled evaluator. `P2632.compact_resource_certificate` checks the 120 triple-orbit indices with `decide +kernel`. The compact theorem checks the resource data; the general orbit-to-packing implication is proved mathematically in the paper and has **not** been separately formalized as a general Lean theorem.

If CI shows compilation errors, fix them and preserve the original verifiable data before describing this as a Lean-verified result.

## Repository map

- `paper/` — LaTeX source and built PDF (v0.2).
- `certificates/constructions/` — the exact 12-block construction and a 10-block benchmark.
- `data/` — 145 triple orbits, 4,761 admissible five-set orbits and their resources.
- `lean/` — the two Lean 4 checking strategies, pinned toolchain, generator and cross-checks.
- `verify/` — independent direct Python and C++ verifiers.
- `src/` — orbit enumeration, symmetry, search and optimization models; optional SciPy / OR-Tools needed for corresponding models.
- `results/` — preliminary literature/novelty assessments and computational report.
- `.github/workflows/verify.yml` — automatic witness and Lean compilation checks.

A DIMACS CNF model for the 13-orbit decision problem can be regenerated by `python3 src/packing_sat.py --target 13`; its mere existence is **not** an UNSAT proof. A large, automatically generated CNF is intentionally excluded from this compact public archive.
